¿Qué puedes hacer con esta API?

Esta API REST te permite integrar el sistema de habitaciones del Hotel VillaDictos en tus aplicaciones. Puedes consultar el catálogo completo de habitaciones aplicando filtros personalizados, obtener información detallada de cada habitación y validar la disponibilidad antes de iniciar el proceso de reserva. Todos los endpoints requieren autenticación mediante API Key en el header X-API-Key, devuelven datos en formato JSON y cuentan con soporte CORS para integraciones desde cualquier origen.

Importante: Para usar esta API necesitas una clave de acceso válida. Incluye tu API Key en todas las peticiones mediante el header X-API-Key. A continuación encontrarás la documentación completa de cada endpoint con ejemplos interactivos y código en diferentes lenguajes.

Guía de Integración

Requisito de Autenticación: Todos los endpoints de la API requieren una API Key válida. Sin esta clave, las peticiones serán rechazadas con un error 403 (Forbidden).

1. Obtener tu API Key

Para utilizar esta API, primero debes obtener una API Key:

  1. Contacta con el administrador del sistema a través de smb96@alu.ua.es
  2. Proporciona la siguiente información:
    • Nombre del proyecto o aplicación
    • Nombre de tu empresa u organización
    • Email de contacto
    • Descripción del uso previsto de la API
  3. El administrador creará tu cliente API y te proporcionará una API Key única con el formato: vd_xxxxxxxxxx...
  4. Importante: Guarda esta clave de forma segura. No la compartas públicamente ni la incluyas en repositorios de código.

2. Pasos para integrar la API:

  1. Configurar autenticación: Incluye tu API Key en el header X-API-Key en todas las peticiones.
  2. Configurar la URL base: Apunta a http://localhost:8080/api/v1 en desarrollo o a tu dominio en producción.
  3. Listar habitaciones: Llama a GET /rooms para mostrar el catálogo de habitaciones disponibles. Aplica filtros según las necesidades de tus usuarios.
  4. Mostrar detalles: Cuando un usuario seleccione una habitación, usa GET /rooms/{id} para mostrar información completa.
  5. Iniciar reserva: Usa GET /bookings/start para validar disponibilidad y obtener la URL de redirección al proceso de reserva del hotel.
  6. Manejo de errores: Implementa manejo de errores para los códigos 400, 403, 404 y 409. La API devuelve mensajes descriptivos en formato JSON.

Ejemplo JavaScript (Fetch API):

// Configurar API Key
const API_KEY = 'tu_api_key_aqui';
const headers = {
  'X-API-Key': API_KEY
};

// Obtener listado de habitaciones
async function getRooms() {
  try {
    const response = await fetch('http://localhost:8080/api/v1/rooms?size=5', {
      headers: headers
    });
    const data = await response.json();
    console.log('Habitaciones:', data.content);
    console.log('Total:', data.totalElements);
  } catch (error) {
    console.error('Error:', error);
  }
}

// Obtener detalle de habitación
async function getRoomDetail(roomId) {
  try {
    const response = await fetch(`http://localhost:8080/api/v1/rooms/${roomId}`, {
      headers: headers
    });
    if (!response.ok) {
      throw new Error('Habitación no encontrada');
    }
    const room = await response.json();
    console.log('Habitación:', room);
  } catch (error) {
    console.error('Error:', error);
  }
}

// Iniciar reserva
async function startBooking(roomId, checkIn, checkOut, guests) {
  const params = new URLSearchParams({
    roomId,
    checkIn,
    checkOut,
    guests
  });
  
  try {
    const response = await fetch(
      `http://localhost:8080/api/v1/bookings/start?${params}`,
      { headers: headers }
    );
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.message);
    }
    
    const booking = await response.json();
    // Redirigir al usuario
    window.location.href = booking.redirectUrl;
  } catch (error) {
    console.error('Error al iniciar reserva:', error);
  }
}

Ejemplo Python (requests):

import requests
from datetime import datetime

BASE_URL = "http://localhost:8080/api/v1"
API_KEY = "tu_api_key_aqui"

# Headers con API Key
headers = {
    'X-API-Key': API_KEY
}

# Obtener habitaciones con filtros
def get_rooms(check_in=None, check_out=None, min_price=None, max_price=None):
    params = {}
    if check_in:
        params['checkIn'] = check_in
    if check_out:
        params['checkOut'] = check_out
    if min_price:
        params['minPrice'] = min_price
    if max_price:
        params['maxPrice'] = max_price
    
    response = requests.get(f"{BASE_URL}/rooms", headers=headers, params=params)
    
    if response.status_code == 200:
        data = response.json()
        print(f"Total habitaciones: {data['totalElements']}")
        return data['content']
    else:
        print(f"Error: {response.status_code}")
        return None

# Obtener detalle de habitación
def get_room_detail(room_id):
    response = requests.get(f"{BASE_URL}/rooms/{room_id}", headers=headers)
    
    if response.status_code == 200:
        return response.json()
    elif response.status_code == 404:
        print("Habitación no encontrada")
        return None

# Iniciar reserva
def start_booking(room_id, check_in, check_out, guests):
    params = {
        'roomId': room_id,
        'checkIn': check_in,
        'checkOut': check_out,
        'guests': guests
    }
    
    response = requests.get(f"{BASE_URL}/bookings/start", headers=headers, params=params)
    
    if response.status_code == 200:
        booking = response.json()
        print(f"Reserva iniciada. URL: {booking['redirectUrl']}")
        return booking
    else:
        error = response.json()
        print(f"Error: {error['message']}")
        return None

# Uso
rooms = get_rooms(min_price=50, max_price=150)
room = get_room_detail(1)
booking = start_booking(2, "2026-03-20", "2026-03-25", 2)

Ejemplo Java (RestTemplate):

import org.springframework.http.HttpEntity;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpMethod;
import org.springframework.web.client.RestTemplate;
import org.springframework.web.util.UriComponentsBuilder;

public class VillaDictosApiClient {
    private static final String BASE_URL = "http://localhost:8080/api/v1";
    private static final String API_KEY = "tu_api_key_aqui";
    private final RestTemplate restTemplate = new RestTemplate();
    
    // Crear headers con API Key
    private HttpHeaders createHeaders() {
        HttpHeaders headers = new HttpHeaders();
        headers.set("X-API-Key", API_KEY);
        return headers;
    }
    
    // Obtener habitaciones
    public PageResponseDTO<RoomListDTO> getRooms(
            LocalDate checkIn, 
            LocalDate checkOut,
            BigDecimal minPrice,
            BigDecimal maxPrice) {
        
        UriComponentsBuilder builder = UriComponentsBuilder
            .fromHttpUrl(BASE_URL + "/rooms");
        
        if (checkIn != null) builder.queryParam("checkIn", checkIn);
        if (checkOut != null) builder.queryParam("checkOut", checkOut);
        if (minPrice != null) builder.queryParam("minPrice", minPrice);
        if (maxPrice != null) builder.queryParam("maxPrice", maxPrice);
        
        HttpEntity<?> entity = new HttpEntity<>(createHeaders());
        
        return restTemplate.exchange(
            builder.toUriString(),
            HttpMethod.GET,
            entity,
            PageResponseDTO.class
        ).getBody();
    }
    
    // Obtener detalle de habitación
    public RoomDetailDTO getRoomDetail(Long roomId) {
        String url = BASE_URL + "/rooms/" + roomId;
        HttpEntity<?> entity = new HttpEntity<>(createHeaders());
        
        return restTemplate.exchange(
            url,
            HttpMethod.GET,
            entity,
            RoomDetailDTO.class
        ).getBody();
    }
    
    // Iniciar reserva
    public BookingRedirectDTO startBooking(
            Long roomId, 
            LocalDate checkIn,
            LocalDate checkOut,
            Integer guests) {
        
        String url = UriComponentsBuilder
            .fromHttpUrl(BASE_URL + "/bookings/start")
            .queryParam("roomId", roomId)
            .queryParam("checkIn", checkIn)
            .queryParam("checkOut", checkOut)
            .queryParam("guests", guests)
            .toUriString();
        
        HttpEntity<?> entity = new HttpEntity<>(createHeaders());
        
        return restTemplate.exchange(
            url,
            HttpMethod.GET,
            entity,
            BookingRedirectDTO.class
        ).getBody();
    }
}
