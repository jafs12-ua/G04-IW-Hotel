API VillaDictos Hotel

API REST para gestión hotelera - Documentación Interactiva

Versión 1.0.0 | Base URL: http://localhost:8080/api/v1

Listar Habitaciones

Consulta habitaciones disponibles con filtros por fechas, precio y temporada. Ideal para mostrar catálogos de habitaciones.

Detalle de Habitación

Obtén información completa de una habitación específica incluyendo equipamiento, servicios y disponibilidad.

Iniciar Reserva

Valida disponibilidad y obtén la URL de redirección para completar el proceso de reserva en el sistema principal.

¿Qué puedes hacer con esta API?

Esta API REST te permite integrar el sistema de habitaciones del Hotel VillaDictos en tus aplicaciones. Puedes consultar el catálogo completo de habitaciones aplicando filtros personalizados, obtener información detallada de cada habitación y validar la disponibilidad antes de iniciar el proceso de reserva. Todos los endpoints son de acceso público, devuelven datos en formato JSON y cuentan con soporte CORS para integraciones desde cualquier origen.

A continuación encontrarás la documentación completa de cada endpoint con ejemplos interactivos que puedes probar directamente desde esta página, así como ejemplos de código en diferentes lenguajes para facilitar tu integración.

Habitaciones

Obtiene el listado de habitaciones con filtros opcionales y paginación.

Parámetros Query (todos opcionales):

Parámetro Tipo Descripción Ejemplo

checkOut Opcional Date Fecha de salida (YYYY-MM-DD) 2026-03-25

maxPrice Opcional Number Precio máximo por noche 150

Reservas

GET /api/v1/bookings/start

Valida la disponibilidad de una habitación y genera URL de redirección al proceso de reserva.

Parámetros Query (todos requeridos):

Parámetro Tipo Descripción Ejemplo
roomId Requerido Number ID de la habitación a reservar 2
checkIn Requerido Date Fecha de entrada (YYYY-MM-DD) 2026-03-20
checkOut Requerido Date Fecha de salida (YYYY-MM-DD) 2026-03-25
guests Requerido Number Número de huéspedes 2

Ejemplo JavaScript (Fetch API):

// Obtener listado de habitaciones
async function getRooms() {
  try {
    const response = await fetch('http://localhost:8080/api/v1/rooms?size=5');
    const data = await response.json();
    console.log('Habitaciones:', data.content);
    console.log('Total:', data.totalElements);
  } catch (error) {
    console.error('Error:', error);
  }
}

// Obtener detalle de habitación
async function getRoomDetail(roomId) {
  try {
    const response = await fetch(`http://localhost:8080/api/v1/rooms/${roomId}`);
    if (!response.ok) {
      throw new Error('Habitación no encontrada');
    }
    const room = await response.json();
    console.log('Habitación:', room);
  } catch (error) {
    console.error('Error:', error);
  }
}

// Iniciar reserva
async function startBooking(roomId, checkIn, checkOut, guests) {
  const params = new URLSearchParams({
    roomId,
    checkIn,
    checkOut,
    guests
  });
  
  try {
    const response = await fetch(
      `http://localhost:8080/api/v1/bookings/start?${params}`
    );
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.message);
    }
    
    const booking = await response.json();
    // Redirigir al usuario
    window.location.href = booking.redirectUrl;
  } catch (error) {
    console.error('Error al iniciar reserva:', error);
  }
}

Ejemplo Python (requests):

import requests
from datetime import datetime

BASE_URL = "http://localhost:8080/api/v1"

# Obtener habitaciones con filtros
def get_rooms(check_in=None, check_out=None, min_price=None, max_price=None):
    params = {}
    if check_in:
        params['checkIn'] = check_in
    if check_out:
        params['checkOut'] = check_out
    if min_price:
        params['minPrice'] = min_price
    if max_price:
        params['maxPrice'] = max_price
    
    response = requests.get(f"{BASE_URL}/rooms", params=params)
    
    if response.status_code == 200:
        data = response.json()
        print(f"Total habitaciones: {data['totalElements']}")
        return data['content']
    else:
        print(f"Error: {response.status_code}")
        return None

# Obtener detalle de habitación
def get_room_detail(room_id):
    response = requests.get(f"{BASE_URL}/rooms/{room_id}")
    
    if response.status_code == 200:
        return response.json()
    elif response.status_code == 404:
        print("Habitación no encontrada")
        return None

# Iniciar reserva
def start_booking(room_id, check_in, check_out, guests):
    params = {
        'roomId': room_id,
        'checkIn': check_in,
        'checkOut': check_out,
        'guests': guests
    }
    
    response = requests.get(f"{BASE_URL}/bookings/start", params=params)
    
    if response.status_code == 200:
        booking = response.json()
        print(f"Reserva iniciada. URL: {booking['redirectUrl']}")
        return booking
    else:
        error = response.json()
        print(f"Error: {error['message']}")
        return None

# Uso
rooms = get_rooms(min_price=50, max_price=150)
room = get_room_detail(1)
booking = start_booking(2, "2026-03-20", "2026-03-25", 2)

Ejemplo Java (RestTemplate):

import org.springframework.web.client.RestTemplate;
import org.springframework.web.util.UriComponentsBuilder;

public class VillaDictosApiClient {
    private static final String BASE_URL = "http://localhost:8080/api/v1";
    private final RestTemplate restTemplate = new RestTemplate();
    
    // Obtener habitaciones
    public PageResponseDTO getRooms(
            LocalDate checkIn, 
            LocalDate checkOut,
            BigDecimal minPrice,
            BigDecimal maxPrice) {
        
        UriComponentsBuilder builder = UriComponentsBuilder
            .fromHttpUrl(BASE_URL + "/rooms");
        
        if (checkIn != null) builder.queryParam("checkIn", checkIn);
        if (checkOut != null) builder.queryParam("checkOut", checkOut);
        if (minPrice != null) builder.queryParam("minPrice", minPrice);
        if (maxPrice != null) builder.queryParam("maxPrice", maxPrice);
        
        return restTemplate.getForObject(
            builder.toUriString(), 
            PageResponseDTO.class
        );
    }
    
    // Obtener detalle de habitación
    public RoomDetailDTO getRoomDetail(Long roomId) {
        String url = BASE_URL + "/rooms/" + roomId;
        return restTemplate.getForObject(url, RoomDetailDTO.class);
    }
    
    // Iniciar reserva
    public BookingRedirectDTO startBooking(
            Long roomId, 
            LocalDate checkIn,
            LocalDate checkOut,
            Integer guests) {
        
        String url = UriComponentsBuilder
            .fromHttpUrl(BASE_URL + "/bookings/start")
            .queryParam("roomId", roomId)
            .queryParam("checkIn", checkIn)
            .queryParam("checkOut", checkOut)
            .queryParam("guests", guests)
            .toUriString();
        
        return restTemplate.getForObject(url, BookingRedirectDTO.class);
    }
}

Guía de Integración

Consejo: La API no requiere autenticación. Puedes empezar a usarla inmediatamente desde cualquier aplicación.

Pasos para integrar la API:

  1. Configurar la URL base: Apunta a http://localhost:8080/api/v1 en desarrollo o a tu dominio en producción.
  2. Usar habitaciones: Llama a GET /rooms para mostrar el catálogo de habitaciones disponibles. Aplica filtros según las necesidades de tus usuarios.
  3. Mostrar detalles: Cuando un usuario seleccione una habitación, usa GET /rooms/{id} para mostrar información completa.
  4. Iniciar reserva: Usa GET /bookings/start para validar disponibilidad y obtener la URL de redirección al proceso de reserva del hotel.
  5. Manejo de errores: Implementa manejo de errores para los códigos 400, 404 y 409. La API devuelve mensajes descriptivos en formato JSON.
Recomendación: Usa los ejemplos de código de la sección anterior como punto de partida para tu implementación.
